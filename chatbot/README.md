# FlashPay Chatbot Service

FastAPI chatbot service for payment support FAQs.

## What It Does

- accepts user questions through `/chat`
- retrieves most relevant FAQ entries using sentence embeddings
- sends grounded prompt to Gemini (if API key is configured)
- falls back to top FAQ answer if LLM is unavailable

## Tech Stack

- Python 3.11
- FastAPI
- Uvicorn
- sentence-transformers
- NumPy
- requests

## Dependencies

Dependency declarations live in `requirements.txt`.

Pinned package versions currently include:

- `fastapi==0.115.0`
- `uvicorn==0.32.0`
- `sentence-transformers==3.2.1`
- `numpy==1.26.4`
- `requests==2.32.3`
- `pydantic==2.9.2`

Install/update dependencies from `chatbot/`:

```bash
pip install -r requirements.txt
```

If dependencies affecting embeddings/model loading are changed, re-run:

```bash
python src/precompute_embeddings.py
```

## Run Locally

From the `chatbot/` folder:

```bash
pip install -r requirements.txt
python src/precompute_embeddings.py
uvicorn src.server:app --reload --host 0.0.0.0 --port 8000
```

Service URL:

```text
http://localhost:8000
```

## Docker Run

Build image:

```bash
docker build -t flashpay-chatbot .
```

Run container:

```bash
docker run -p 8000:8000 -e GEMINI_API_KEY=<your_key> flashpay-chatbot
```

Note: embeddings are precomputed at image build time in the Dockerfile.

## Environment Variables

- `GEMINI_API_KEY` (optional): enables LLM-generated answers

If missing, chatbot still responds using retrieval fallback mode.

## API

### Health

- Method: `GET`
- Path: `/health`
- Response example:

```json
{ "status": "ok" }
```

### Chat

- Method: `POST`
- Path: `/chat`
- Request body:

```json
{ "message": "What does CREATED status mean?" }
```

- Response body:

```json
{
  "reply": "CREATED means the payment has been submitted but not yet validated...",
  "source": "llm"
}
```

`source` can be:

- `llm` - answer generated by Gemini
- `fallback` - direct FAQ fallback used
- `no_match` - no FAQ above confidence threshold

## Data Files

- `data/faqs.json` - FAQ corpus used for retrieval
- `data/faq_embeddings.npy` - precomputed FAQ embeddings

If `faq_embeddings.npy` is missing, run:

```bash
python src/precompute_embeddings.py
```
